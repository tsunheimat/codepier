# Audit sessions and original receipts

Audit records host session identifiers and permitted resource/operation references,
not chat transcripts, inferred goals or task completion. Normal MCP use needs no
manual association. The authenticated Connection remains the ownership boundary;
sharing a Profile or workspace does not share private sessions.

Global human audit views enumerate currently authorized workspaces independently,
without a current-space selector, and keep owner-private session metadata. Resource
and receipt reads recheck current authorization. Operations and execution sessions
retain their original identities when a display setting or default device changes.

See [Workspace setup and contracts](WORKSPACES.md) for the complete development model.
