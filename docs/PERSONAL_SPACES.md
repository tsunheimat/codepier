# Workspaces without a current-space selector

A personal workspace is an ordinary workspace owned by its creator, not a
legacy/default authorization container. Open workspaces directly from the workspace
list. Browser tabs can use different explicit workspace URLs independently.

There is no current-space switch, header, account setting or fallback. A resource
knows its workspace; an MCP Connection binds its workspace/Profile at authorization.
Global account/SSO administration remains distinct from workspace membership.

See [Workspace setup and contracts](WORKSPACES.md) for the complete development model.
